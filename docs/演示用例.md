# 演示用例(电商客服版)

打开首页即"咨询对话"页,右侧为 Agent Loop 轨迹可视化。

## 一、商品咨询(自动选工具)
1. 输入"扫地机器人多少钱?" → 观察轨迹:recall_playbook → product_search → 回答含价格/卖点。
2. 输入"耳机降噪效果怎么样?有没有人买过?" → 轨迹含 buyer_reviews,回答引用真实买家评价。

## 二、自纠错闭环(核心演示)
1. 输入"X1 Pro 能清扫 200 平的复式吗?" → 知识库未命中 → **自动转人工**,生成工单。
2. 切到"后台审核" → 给工单补充答案 → 点"通过并入库"。
3. 回咨询页再问同一问题 → **直接答对**。
4. 顶部看板:知识库条目数 ↑、转人工率 ↓。

## 三、店长教学(边聊边教)
1. 切到"店长教学"页 → 教一条新套路(如"客户砍价就送清洁剂+延保")。
2. 回咨询页问"能便宜点吗" → AI 按新套路应答。

## 四、AI 自进化
- "实测纠偏"页:对 AI 刚才的回答给点评,AI 当场重答,确认后自动固化进套路库并更新总纲。
- "套路总纲"页:查看全部样本归纳出的销售策略总纲,可手动改写。

## 五、业务设定
- 后台"AI 业务设定"可改全局人设与铁律(如"满 999 减 50 的优惠话术"),实时生效。
